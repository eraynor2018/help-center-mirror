# How to Message a Seller

If you have questions about gear that you'd like to ask before purchasing, you can message the seller directly from the item page! When you're on an item page on sidelineswap.com, you can find the option to "Message Seller" on the bottom of the item information on the right.

![Untitled design (13).png](https://help.sidelineswap.com/hc/article_attachments/9954987977372)

![Screenshot 2023-08-10 092241.png](https://help.sidelineswap.com/hc/article_attachments/9954955974940)

From the app, you can find the option to "Message Seller" right under the title and photos of the listing.
