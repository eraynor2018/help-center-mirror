# What is SidelineSwap's return policy?

**Buyers**: If you receive an item that isn’t as advertised, you may return it for a full refund. Learn more [here](https://help.sidelineswap.com/hc/en-us/articles/360010362019-How-the-Refund-Return-Policy-Works "https://help.sidelineswap.com/hc/en-us/articles/360010362019-How-the-Refund-Return-Policy-Works").

**Sellers**: You are not obligated to accept the return of an as-advertised item. Learn more [here](https://help.sidelineswap.com/hc/en-us/articles/360010360959-How-are-Sellers-Protected-on-SidelineSwap "https://help.sidelineswap.com/hc/en-us/articles/360010360959-How-are-Sellers-Protected-on-SidelineSwap").

**Seel**: Buyers who purchase Seel's return assurance service for a small fee at checkout may return their items to Seel for a refund. Learn more [here](https://help.sidelineswap.com/hc/en-us/articles/10714161709212-What-is-Return-Assurance-powered-by-Seel "https://help.sidelineswap.com/hc/en-us/articles/10714161709212-What-is-Return-Assurance-powered-by-Seel").
