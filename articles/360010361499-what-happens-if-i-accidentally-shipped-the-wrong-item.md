# What happens if I accidentally shipped the wrong item?

There is a solution if a Seller happens to send the wrong item(s) to one or more Buyers. SidelineSwap can generate the necessary shipping labels to rectify the situation **provided the Seller is willing to cover the costs**. Please [contact SidelineSwap](https://help.sidelineswap.com/hc/en-us/requests/new?ticket_form_id=360000525400) to get the process started.
