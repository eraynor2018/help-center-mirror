# What is Return Assurance powered by Seel?

## What you need to know:

* SidelineSwap Buyer Protection covers items that arrive not as advertised.
* Return Assurance powered by Seel is an optional add-on that allows returns within 7 days of delivery when the item arrives as described.

---

## For more information...

SidelineSwap’s **Buyer Protection** guarantees that if an item doesn’t arrive as advertised, you can open a dispute within **72 hours** of delivery for a full refund.

But what if the item *is* as described — you just don’t want it anymore, or it doesn’t fit quite right? That’s where **optional** **Return Assurance powered by Seel** comes in.

With Seel, you can return any item for any reason, within **7 days** of delivery — no questions asked.

### **Purchasing Seel Return Assurance**

Seel Return Assurance is added to your purchase by default during checkout on SidelineSwap. That said, Seel is an *optional* add-on that you can always disable at checkout if you do not wish to include it with your purchase.

* The cost of Seel varies depending on the item’s price and category.
* This small fee is **non-refundable**, even if you decide not to return the item.

💡 **Tip:** Adding Seel is the best way to shop worry-free — you’ll always have the option to return if the item doesn’t work out.

### Comparing SidelineSwap Buyer Protection & Seel Return Assurance

|  |  |  |
| --- | --- | --- |
|  | **SidelineSwap Buyer Protection** | **Seel Return Assurance** |
| **Items eligible to be returned** | Items that arrive not as advertised | Any item can be returned as long as it is still in usable condition |
| **Window to request a return** | Within 72 hours of delivery, before the swap has been accepted | Within 7 days of delivery regardless of if the swap has been approved |
| **Cost** | Free on all SidelineSwap purchases | A varying fee, dependent on the type and cost of the item |

### **Using Seel Return Assurance**

**Using Seel Return Assurance**

If you purchased Seel Return Assurance, you can return your item within **7 days of delivery** — even if it arrived as described.

To start a Seel return, follow the steps outlined here:

Please note:

* You’ll be refunded the **item price and original shipping cost**
* You’re responsible for **return shipping costs**

Returns are handled directly through Seel and don’t require contacting SidelineSwap Support.
