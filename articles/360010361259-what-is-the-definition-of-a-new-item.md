# What is the Definition of a "New" Item?

Unless an item has never been used, then it should not be listed as "New.” If an item has been used once, it should be labeled as "Used.” 

We understand that items that have been worn once are essentially "Like New" from a performance perspective. The Seller is free to specify that the item is in "Like New" condition in the item title or description.
