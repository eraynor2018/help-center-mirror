# How to Change a Shipping Address

Please visit the [Shipping Information](https://sidelineswap.com/settings/addresses) page to update your shipping address.

If you need to edit the address on a shipping label after a purchase has already been made, the seller will can generate a new shipping label from their swap page by clicking "Update Label" and then "Update Addresses". The seller can then generate a new label only if one or both of the addresses have been updated.

Buyers: Please ensure your correct "**Ship to**" address is selected.

Sellers: Please ensure your correct "**Ship from**" address is selected.
