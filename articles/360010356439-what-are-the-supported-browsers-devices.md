# What are the Supported Browsers & Devices? 

For the best experience possible, please make sure your device and browser meets the following minimums. If you experience any bugs or difficulties, please contact our Support team.

## iOS Users

*We support iOS devices (iPhones and iPads) using these iOS versions and browsers:*

* iOS 10.0+ Mobile Safari

## Android Users

*We support Android devices (phones and tablets) using these OS versions and browsers:*

* Android OS 4.4+ (KitKat) Chrome

## Windows Users

*We support Windows devices (laptops, computers, and tablets) using these browsers:*

* Google Chrome 40+
* Internet Explorer 11.0+
* Firefox 40+
* Microsoft Edge 12.0+

## Mac Users

*We support Mac devices (laptops and computers) using these browsers:*

* Safari 9.0+
* Google Chrome 40+
* Firefox 40+
