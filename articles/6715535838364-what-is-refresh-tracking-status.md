# What is "Refresh Tracking Status"?

The status of a swap depends on the shipping carrier’s tracking scans. A carrier must scan a package when the package is dropped off for the swap to be considered “In Transit”. The carrier must subsequently scan the package as *delivered* to start the 72-hour clock before the funds are automatically released. When the carrier makes these scans, SidelineSwap updates the swap status accordingly. This process almost always goes off without a hitch, however, on occasion, the carrier’s tracking status and the SidelineSwap swap status are not fully aligned. 

To rectify this issue, we’ve added a “Refresh Tracking Status” button that allows sellers to update their swaps on their own. If your tracking page shows the package is in transit, but the swap is still in your “Ship Now” folder, simply refresh the tracking status to update the swap. Likewise, if the tracking shows the package has been delivered but it’s still “In Transit” on SidelineSwap, sync the tracking status to update the swap on SidelineSwap.
